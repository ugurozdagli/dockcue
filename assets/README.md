# Visual assets

The SVG illustrations are original DockCue project artwork and use the repository MIT license. They are descriptive illustrations, not product photographs or live screenshots. No official Logitech logo, product photography or endorsement is included.

`screenshot-en.png` is an app-only screenshot of the earlier 1.2.0 interface. It contains no personal paths, identifiers or desktop background. The current 1.2.1 compact interface is represented by `interface-overview.svg`, explicitly labeled as an illustration with sample values.
