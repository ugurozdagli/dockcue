# Changelog

## 1.2.1

- Fix mix snapping back to an old non-centered baseline. Media mode now always returns to center.
- Add explicit center control without sending a media key; suppress delayed HID restoration echoes.
- Compact main window with expandable settings and activity.
- Show last reported charging-dock / fully-charged status alongside battery percentage.

## 1.2.0

First public DockCue release.

- Microphone-open / muted cues and configurable Voice or Game play/pause.
- System tray, optional Windows startup, persistent settings.
- Automatic English/Turkish selection and manual language switch.
- Clear USB-base status, battery freshness, running indicator and uptime.
- Rotating local logs, sanitized errors and recoverable worker retries.
- Local-only G HUB allowlist, tests and clean Windows release build workflow.
